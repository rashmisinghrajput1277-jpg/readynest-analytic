# ⚡ ReadyNest Messenger Analytics Dashboard

An end-to-end user engagement and predictive messaging analytics platform built for ReadyNest. This application processes real-time chat data to deliver actionable insights on user activity, peak communication volumes, and future platform growth.

## 🚀 Key Features

* **Core Metric Tracking:** Real-time Daily Active Users (DAU), total message volume, active communicators, and media attachment counts.
* **Interactive Visualizations:** Dynamic line graphs and leaderboard charts built with Plotly for tracking hourly and daily activity trends.
* **Dynamic Filtering:** Filter data on the fly by custom date ranges and specific chat channels (1-to-1, Group, Broadcast).
* **🌟 Predictive ML Forecast (Bonus Feature):** Integrated Scikit-Learn Linear Regression model that analyzes historical trends to project engagement volume 14 days into the future.
* **Aesthetic Dark UI:** Designed with a custom modern dark theme and glassmorphism cards for maximum visual appeal.

## 🛠️ Tech Stack

* **Language:** Python
* **Frontend / Framework:** Streamlit
* **Data Processing:** Pandas, NumPy
* **Data Visualization:** Plotly
* **Machine Learning:** Scikit-Learn
